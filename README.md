# FQA Chatbot 🤖

A simple **FAQ (Frequently Asked Questions) Chatbot** built using Python.
This chatbot responds to predefined questions related to Python and Artificial Intelligence.

## 📌 Features

* Responds to `hi` with a greeting.
* Answers **"what is python?"**
* Answers **"what is ai?"**
* Responds to `bye` and exits the program.
* Displays a default message for unknown questions.
* Simple and beginner-friendly Python project.

## 🛠️ Technologies Used

* **Python 3**
* `input()` and `print()`
* `if-elif-else` conditions
* `while` loop

## 🚀 How to Run

1. Make sure Python 3 is installed on your computer.
2. Save the Python code in a file, for example:

```text
chatbot.py
```

3. Open the terminal or command prompt.
4. Run the following command:

```bash
python chatbot.py
```

## 💬 Example

```text
FQA Chatbot
Enter Bye To Exit.

You: hi
Bot: Hello , How can i help you?

You: what is python?
Bot: Python is a Programming Language

You: what is ai?
Bot: AI is an Artificial Intelligence

You: bye
Bot: Bye Have a Good Day!!
```

## 📚 Supported Questions

| User Input        | Chatbot Response                 |
| ----------------- | -------------------------------- |
| `hi`              | Hello, How can I help you?       |
| `what is python?` | Python is a Programming Language |
| `what is ai?`     | AI is an Artificial Intelligence |
| `bye`             | Bye Have a Good Day!!            |

## ⚠️ Note

The chatbot can answer only the questions that are predefined in the program.
If the user enters another question, the chatbot displays:

```text
Bot: Sorry,I don't understand your question
```
